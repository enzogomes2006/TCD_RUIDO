# Evidencias reais

Esta pasta nao contem resultados reais. Cada rodada deve ter arquivos RX, TX e ruido, captura de tempo e identificacao da versao do codigo.
Nao mova CSVs de simulacao para esta pasta. Nao preencha perdas ou bits alterados por suposicao.

Nomes sugeridos: `sum8_modo0_rx.csv`, `sum8_modo0_tx.csv`, `sum8_modo0_noise.csv`.
Feche uma rodada apenas apos reconciliar cada sequencia transmitida com RX e injetor.
